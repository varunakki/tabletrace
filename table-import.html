TABLETRACE · TABLE IMPORT

Turn a table picture into data.

Photo or video frame → read text → review cells → clean → download CSV and table PNG.

1. Choose a table photo or video

Clear printed English tables work best. No handwriting guarantee. Photos: 20 MB / 24 megapixels. Videos: 200 MB / 10 minutes; only one selected frame is read.

OCR runs in this browser using Tesseract.js. Internet is needed to download the OCR library and English model from a CDN. Files are not sent for recognition. Review every value: table structure and numbers can be misread.

Choose a file to start.

2. Mark the columns

Enter the number of columns. Drag the green vertical dividers so each separates two table columns. Use a straight, tightly framed table; titles and notes may become extra rows that you can delete.

3. Review and correct

Low-confidence OCR text is shown in amber. Unmarked text can still be wrong. Fix merged or split cells, numbers, headings, and extra rows before continuing.
